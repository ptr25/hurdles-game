#  Multiplayer Racing Game 🏎️

One of my early JavaScript projects, and my first time exploring **databases and multiplayer game development!** 🚗

Built using **p5.js, p5.play, and Firebase Realtime Database**, this is a 4-player racing game where players can join and race together.

This was when I first learnt how a database could store and sync information between different players, which honestly felt pretty cool!

I also got introduced to **game states** — understanding how a game switches between waiting for players, actually playing, and ending. Along the way, I worked with sprites, animations, frames, classes, and game loops.

Looking back, it's fun seeing how I slowly went from making simple animations to understanding how different parts of a game communicate and work together...i really loved the process of learning how cool coding and everything about it was
